# クレジットカード管理ツール (Credit Card Manager)

自身が保有するクレジットカードの締め日・支払日を登録し、買い物をした日付から「次回いつ支払うか」「支払日まで何日猶予があるか」をひと目で確認・比較できるWebツールです。

## こんなときに

- 複数のクレジットカードを持っていて、カードごとの締め日や引き落とし日を覚えきれないとき
- 「今日このカードで買ったら引き落としは何月何日になるか」をすぐに確認したいとき
- 大きな買い物をするときに、最も支払い猶予が長くなるカードを選びたいとき
- 外部の家計簿サービスにカード番号やログイン情報を預けたくないとき

## 主な機能

- **カード設定の管理**: カード名、締め日（指定日／月末）、支払月（当月／翌月／翌々月等）、支払日、休日補正（翌営業日／前営業日等）を登録・編集・削除
- **締め日・支払日カウントダウン**: 直近の締め日・支払日までの残り日数を自動表示
- **利用日シミュレーター**: カレンダーで買い物予定日を選ぶだけで、全カードの「支払予定日」と「支払いまでの猶予日数」を一括計算・比較
- **データ管理（バックアップ・復元）**: 設定データをJSONファイルとしてパソコンや端末に書き出し・読み込み

## 使い方

### ブラウザで使う（かんたん）

1. [ツールを開く](https://zero-dev.jp/credit-card-manager/) をクリックします。
2. 画面右上の「カード追加」ボタンを押します。
3. 「カード名」「締め日」「支払月」「支払日」を入力し、必要なら「休日の扱い」や「メモ」を設定します。
4. 「保存する」を押すと、カード一覧に登録されます。
5. 画面下部の「利用日シミュレーター」で買い物をした日付を選択すると、各カードの支払予定日と猶予日数が表示されます。

### ダウンロードして使う（パソコンに保存する場合）

1. [Releases](https://github.com/tk030-lotto/credit-card-manager/releases) から最新のソースコード（zip）をダウンロードして解凍します。
2. Windows をお使いの場合は、フォルダ内の「ツール起動.bat」をダブルクリックすると、ブラウザでツールが起動します。

## うまくいかないとき

- **登録したカードが消えたとき**: ブラウザのCookieやサイトデータを消去すると、保存された設定も消去されます。定期的に画面右上の「データ管理」ボタンからバックアップ（JSON保存）を行ってください。
- **支払日が祝日・連休と重なるとき**: カード会社によって「翌営業日」か「前営業日」かが異なります。カード設定の「休日の扱い」がご利用のカードの規約と合っているかご確認ください。

## 動作環境

- モダンブラウザ（Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge 最新版）
- スマートフォン（iOS Safari, Android Chrome）およびPCに対応

## 制限・注意

- 本ツールは日付サイクルのシミュレーションを行うものであり、銀行口座の残高確認や実際の引き落とし処理は行いません。
- カード番号、有効期限、セキュリティコード、暗証番号などの機密情報は一切取り扱いません（入力欄も存在しません）。
- データはお使いの端末のブラウザ（localStorage）内にのみ保存されます。

## 外部通信

- Google Fonts のスタイルシートおよびフォントファイルの読み込みのみ行います（利用者の入力データや操作履歴の外部送信は一切行いません）。
